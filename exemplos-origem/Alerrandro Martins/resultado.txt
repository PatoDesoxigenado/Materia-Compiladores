---------------------------------------- tipos de dados e variáveis

=== EXEMPLO 1: TIPOS DE DADOS E VARIÁVEIS ===
Sistema de Carrinho de Compras

=== 1. Tipos primitivos: tipo estático, valor zero e tamanho ===
  TIPO           VALOR                ZERO VALUE TAMANHO
  int            42                   0          8 byte(s)
  int8           127                  0          1 byte(s)
  uint           42                   0          8 byte(s)
  float64        3.14                 0          8 byte(s)
  string         "compiladores"       ""         16 byte(s)
  bool           true                 false      1 byte(s)
  rune (int32)   'Ç' (199)            0          4 byte(s)
  byte (uint8)   65 ('A')             0          1 byte(s)
  *Produto       <nil>                <nil>      8 byte(s)
  Observações:
    - string ocupa 2 palavras (endereço dos dados + comprimento), não 1 byte por caractere.
    - *Produto ocupa 1 palavra: ele guarda o endereço da struct, não a struct inteira.
    - a letra 'Ç' é um rune (código 199) e ocupa 4 bytes, mas o texto completo "compiladores" ocupa 12 bytes.
    - float64 é binário de precisão: 0.1+0.2 não dá 0.3 exatamente.
      0.1 + 0.2 = 0.29999999999999998890
      arredondado para 2 casas = 0.30

=== 2. Zero values: `var x T` sempre nasce inicializado ===
  int     -> 0
  float64 -> 0.00
  string  -> "" (len=0)
  bool    -> false
  slice   -> [] (len=0, cap=0)
  map     -> map[] (len=0)
  Cliente -> nome="" cidade="" newsletter=false
  leitura em map nil: descontos["frete"] = 0.00
  (escrever em map nil causaria panic: é preciso antes usar make)
  após append no slice nil: [P M G] (len=3, cap=3)

=== 3. Structs: literais, campos nomeados e aninhamento ===
  Cliente: Alerrandro Martins <alerrandro@uern.br>
  Endereço aninhado:  Rua das Acácias, 120 - Mossoró/59633-070
  Endereço posicional: Av. Presidente Dutra, 45 - Parnamirim/59633-000
  Assina newsletter: true
  original tem numero 120, mas a copia tem 999
  (structs são valores: a cópia é independente do original)

=== 4. Slice: len, cap, append, copy e fatiamento ===
  literal: [camiseta calca bone] (len=3, cap=3)
  após append: [camiseta calca bone tenis meia] (len=5, cap=6)
  lista[1:3] = [calca bone]
  alterando meio[0], a lista original virou [camiseta CAMISA bone tenis meia] (array compartilhado)
  com copy, a lista continua [camiseta CAMISA bone tenis meia] e a cópia é [jaqueta CAMISA bone tenis meia]
  após remover o segundo item: [camiseta bone tenis meia]
  lista[:cap] expõe o array inteiro: [camiseta bone tenis meia meia ] (len=6)
  make([]int, 0, 4) + append: [10 20 30] (len=3, cap=4)

=== 5. Escopo: pacote, função e bloco ===
  escopo de pacote: cupomPromocional = 15%
  escopo da função: desconto = 5%
  dentro do bloco (sombreada): desconto = 30%
  fora do bloco, a externa continua: desconto = 5%
  total declarado na função: 120
